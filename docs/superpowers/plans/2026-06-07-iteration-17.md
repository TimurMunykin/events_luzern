## Verification model
No unit tests. "Tests" = (a) asset-lint script (same idea as CI: inline `<script>` parses, all `assets/...` refs exist), (b) file presence/size checks, (c) local preview. Asset-lint helper used throughout:

```bash
node - "$1" <<'NODE'
const fs=require('fs'),path=require('path');
const file=process.argv[1];
const html=fs.readFileSync(file,'utf8');
const m=html.match(/<script>([\s\S]*?)<\/script>/);
if(m){ new Function(m[1]); }
const urls=[...html.matchAll(/(?:url\('([^']+)'\)|data-src="([^"]+)"|data-poster="([^"]+)"|src="([^"]+)"|poster="([^"]+)")/g)]
  .flatMap(x=>x.slice(1).filter(Boolean)).filter(u=>u.startsWith('assets/'));
const dir=path.dirname(file);
const missing=[...new Set(urls)].filter(u=>!fs.existsSync(path.join(dir,u)));
if(missing.length){ console.error('MISSING:\n'+missing.join('\n')); process.exit(1); }
console.log(path.basename(file)+': script OK, '+new Set(urls).size+' asset refs OK');
NODE
```
Save this as `/tmp/assetlint.sh` (wrap as `#!/usr/bin/env bash` + the block) and `chmod +x` it; call `bash /tmp/assetlint.sh prototypes/aurora-v17X.html`.
